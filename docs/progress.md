## 決めた方針

| 項目 | 方針 |
| --- | --- |
| 開発場所 | `Ronpa-org/ronpa` を共用。`origin`のみを使用し、自分用のforkは作らない |
| 技術・開発 | あなた（`wasanemon`）が担当 |
| ホスティング | 当面は友人（`lilg62288`）が既存のVercel／Renderを管理する |
| 招待・課金 | あなたへのVercel／Renderの招待を開発の前提にしない。招待のためだけの有料化は進めない |
| GitHubの共同管理者 | 友人のOrganization Owner化は保留 |
| 公開方法 | GitHubの変更を既存環境へ自動デプロイする構成を目指す。あなたのコミットで実際に動くことを確認する |
| 将来の見直し | あなたが管理画面での設定変更・障害対応まで担う必要が出たら、管理権限の分担を再検討する |

GitHubへの参加と、Vercel／Renderの管理画面への参加は別の権限。
招待がなくてもGitHubでの開発は進められるが、友人の管理画面をあなたが直接操作できるわけではない。
